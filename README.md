# Pre-Save Duplicate Bug Detector

## Main notebook

`vasantha_Duplicate_Bug_Detector.ipynb`

## Install packages

```bash
pip install -r requirements.txt
```

## Run the project

1. Open `vasantha_Duplicate_Bug_Detector.ipynb`.
2. Run the notebook from the first cell to the last cell.
3. Enter the GitHub token only when the notebook asks for it.
4. Do not upload a real GitHub token or `.env` file.

## Run the Streamlit app

After the notebook creates the model artifact, run:

```bash
streamlit run app/streamlit_app.py
```
